Software Engineer focused on **enterprise Java applications**, **Kotlin/Android projects** and **secure software engineering**.

I work across the full development lifecycle: requirements analysis, technical design, implementation, testing, deployment and production troubleshooting. My cybersecurity background adds a security-first perspective to the way I design and maintain software.

- 🏗️ Building and maintaining enterprise applications with **Java 17, Spring Boot, Angular and Oracle**.
- 🔎 Working with complex business rules, advanced searches, data exports, statistics and high-volume SQL queries.
- 📱 Developing personal Android projects with **Kotlin, Jetpack Compose and Media3/ExoPlayer**.
- 🔐 Master's degree in Cybersecurity, with a focus on secure development, application security and systems.
- 🎯 Interested in Java backend, full-stack Java/Angular, Kotlin/Android and secure software engineering roles.

## 🚀 Featured project

### 📱 [UnderAnime Rebirth](https://github.com/4bysss/UnderAnimeRebirth-Releases)

A personal Android project used to explore real-world application architecture, multimedia playback, local persistence and automated distribution.

- Built with **Kotlin and Jetpack Compose**.
- Multimedia playback using **Media3/ExoPlayer** and WebView-based fallbacks.
- Playback-progress persistence and resume-from-last-position support.
- Full-screen playback, remote version checks and automated GitHub releases.
- Private source code with public APK releases and version metadata.
